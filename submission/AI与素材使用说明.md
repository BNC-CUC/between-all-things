# 《万物之间》v0.4.0 AI及素材使用说明

准备日期：2026-10-18。此文件供投稿者审阅、补齐署名后发布为在线说明。它目前是本地文件，没有在线链接，也未上传TapTap。

## 使用范围

本作品使用AI协助讨论设计、编写与改写HTML/CSS/JavaScript、整理开发文档。并非全程使用TapTap制造开发，不申报“最佳TapTap制造奖”。不把AI辅助写成全人工作品。

| 内容 | 来源与生成方式 | 本版处理 |
| --- | --- | --- |
| 湿地背景 `dist/assets/wetland.png` | 原项目ART_DIRECTION.md记载，2026-10-17通过OpenAI ImageGen生成 | 原样复用；本轮未生成新位图 |
| 微光、植物、蚂蚁、鸟、果实、种子、路径、粒子 | 原版与本轮AI辅助编写的Canvas程序绘制 | 复用并修改，非外部游戏素材 |
| 页面图标与界面 | 原版SVG与HTML/CSS，本轮AI辅助扩展 | 保留既有标识，不使用第三方字体下载或组件库 |
| 风声、和声、闪光、生长、鸣叫、资源音效 | 既有AI辅助编写Web Audio合成程序 | 原代码复用，没有外部配乐或录音 |
| 投稿图标与封面 | 原SVG几何导出、原AI湿地画排版 | 新增PNG导出物，非新生成AI原画；不是实机截图 |
| 系统字体 | 操作系统字体栈 | 未打包、分发字体文件 |

原画生成提示词完整保留在项目 `ART_DIRECTION.md`。资产SHA-256见 `submission/素材清单.json`。原GameJam完整时间戳归档与逐文件摘要可追溯此前版本。

## 奖项与口径

官方答疑允许AI，且要求投稿附AI生成资产说明在线文档。官方文案为“美术资产由AI生成，且占比50%以上”的游戏不参加最佳美术奖评选。这里按50%及以上理解；具体比例统计口径未得到主办方确认。

本作品的主环境原画为AI生成，程序美术也有AI编写参与，不以“只有一张背景”主张低于阈值，不保证最佳美术奖资格。投稿表格应如实勾选AI/素材使用情况，必要时请主办方确定口径。

本轮没有新增第三方图像、音乐、视频或商业素材包。原画记录未使用参考视频截图或配乐作为资产。但没有独立完成全部历史资产、代码权利链审计，也不凭这一说明作法律授权保证。

投稿主体、署名与授权人应由真实队长/团队填写。不要把AI工具名填写成拥有团队权利的自然人，也不要伪造生成记录、购买记录或原创证明。
