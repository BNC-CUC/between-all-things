# Mac 本地预览启动

在访达中双击对应 .command 文件，会启动所需本地服务并在默认浏览器打开地址：

- 启动-v0.5-河湾之初.command → http://127.0.0.1:5050
- 启动-v0.4.1-保底试玩.command → http://127.0.0.1:4176

若已是正确页面则复用现有服务；若端口被其他内容占用则停止并提示，不终止未知进程。不安装依赖、不重新构建、不修改旧发行包。

由脚本新启动时，请保持终端窗口打开；Control+C或关闭窗口会停止该服务。重启电脑后可再次双击。既有后台服务会直接打开浏览器，脚本退出不停止那个后台服务。

仅本机访问，不能把127.0.0.1地址发送给手机或朋友作为公网链接。若浏览器提示无法连接，先检查是否为这台Mac上的浏览器、脚本终端是否报错。

本轮脚本仅做zsh语法检查；没有自动启动浏览器。服务HTTP可响应不等于用户打开成功，也不等于游戏人工试玩验收。
