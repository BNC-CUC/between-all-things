# 河湾之初 v0.5-loop.1

首条真实创造循环原型：播种→环境驱动生长→果实→自主寻路运输。占位素材、实验数值，未通过人工试玩验收，不替代v0.4.1参赛候选。刷新重置，无存档/声音。

npm ci；npm run check（纯空间/模拟断言，无浏览器）；npm run build；npm start（本机5050）。build/riverbend-graybox-offline.html为内联离线候选，实际离线浏览器运行未人工验收。分发附许可证。

完整操作与边界见../docs/MANUAL_ACCEPTANCE_V05.md。鼠标轻点工具，拖动环绕，右键平移，滚轮缩放；俯视拖动平移；触屏双指缩放平移。先在左岸播种并浇水/补肥，成熟结实后可两次点击搬放果实。水面和隔岸可达性由世界格决定，镜头不改变模拟。
