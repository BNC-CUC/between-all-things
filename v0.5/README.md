# 河湾之初 v0.5 空间灰盒

架构获主设计批准；接口数值待审。此构建只有三维地形、静态占位植被、相机和落点标记，没有生态创造循环、存档或声音。不能代替正式参赛版。

安装依赖 npm ci；运行 npm run check 和 npm run build；npm start 启动仅本机服务器。build/riverbend-graybox-offline.html 为自包含灰盒HTML，运行不需要CDN；实际浏览器和手机兼容性未测试。build内包含许可证，分发时一并提供。

水平环绕、正常俯仰、缩放/平移、正交顶视、复位已编码。实验连续俯仰约-89.89°..89.89°，精确上下端点由顶视/底视按钮提供，未实现穿越极点的连续旋转。地下只观察。点击标记位置来自真实地形射线，静态检查已覆盖不同镜头命中同一点；人工体验待验收。
