## 1. 视觉职责

保留柔和、低饱和、纸片质感；通过实际地形高度、透视、遮挡、投影与不同尺度形成空间。可操作对象必须与背景区分，局部回应先可见，随后群体变化可追踪。高亮、轮廓、短暂局部动效表达“发生了什么”，不靠全屏光效代替生态。

艺术动画可表现生长过程和风动，但出生、成熟、资源产出、群体迁移必须来自模拟。未经确认不新增物种、神迹、章节奖励或固定生态演出。

## 2. 坐标、模型与碰撞

| 项目 | 约定 |
| --- | --- |
| 坐标 | 右手系，+Y 上、+X 东、+Z 南；1 单位 1 米 |
| 朝向 | 模型本地前方 +Z，上方 +Y；默认旋转零、缩放一 |
| 枢轴 | 植物/石块在地面接触中心；移动生命在身体地面投影中心；飞行高度由世界变换表达 |
| 导出 | 烘焙非统一缩放，禁止负缩放镜像；模型真实尺寸写入清单 |
| 地形 | 主工程生成/管理高度网格；美术不另造一张与拾取不一致的高度图 |
| 碰撞 | 可视网格与简化拾取体分离；资源占地及可达性由规则配置决定 |
| 变换 | 根节点负责世界位置/朝向；子节点负责摆动、翼振等局部动画，不使用 root motion 推动物理实体 |

主要对象支持 360°观看；不可用一张固定正面图承担当近景立体主角。植被可用交叉薄片或薄体模型，侧面与背面不得消失。必要时设置双面材质，但有明确正反外观的纸片要提供背面。地下实验视角不要求新增地下玩法或完整地下生态资产。

## 3. 文件格式与贴图

运行模型首选 GLB（glTF 2.0），纹理尽量嵌入，避免丢失外链。GLTFLoader 为对应导入入口。[官方文档](https://threejs.org/docs/pages/GLTFLoader.html) 源文件保留 .blend 或原创制作格式，不作为运行依赖。

贴图 PNG 或 WebP；需要无损透明边缘优先 PNG。基础颜色按 sRGB，法线/粗糙度等数据贴图按线性数据解释，由主工程加载器统一设置。导出 glTF 材质，不依赖制作软件专用节点。首轮不要求法线贴图或复杂 PBR。

植被剪影优先 alpha cutout（建议阈值 0.5，按资产记录）而不是大量半透明叠层。半透明限水、少量粒子等；透明排序不能替代真实深度。图集留边至少 4px 并扩色，防止缩小后白边。不得把固定光照方向的强投影画死在贴图中。

## 4. 动画与反馈

可用 clip 名：idle、move、carry、react；植物使用 seed、sprout、grow、mature、fruit、wilt 的状态外观或相应过渡。只有物种实际需要的状态才交付，以上不是新增物种清单。循环片段首尾连续，状态切换支持中断；所有 clip 标明秒数、循环与适用状态。植物生长比例由模拟 growth 驱动，不能由动画播放完毕决定成熟。

| 真实事件 | 视觉响应 | 限制 |
| --- | --- | --- |
| command.accepted | 命中位置短暂落点/范围回应 | 只确认动作被接受，不宣告生态成功 |
| command.rejected | 预览变为不可放置并显示简短原因 | 不消耗资源、不播放成功动效 |
| seed.placed | 对应种子落地/落点微动 | 与提交后的实际位置一致 |
| plant.germinated | 对应实体抽芽与轻微轮廓提示 | 密集出生按区域聚合提示，真实植株仍逐个存在 |
| plant.stage_changed | 更新对应阶段外观 | 不反向写模拟状态 |
| resource.transferred | 搬运者/资源点短回应 | 只在真实交接后触发 |
| ecology.cluster_changed | 群落边界/色调变化可读 | 指标和触发阈值待设计；不能按时间固定演出 |

缩远后可用群落级轮廓、密度和活动路径，缩近显示个体；不要求所有个体在远景同样醒目。保持静态地形、动态生命、交互预览三者层次。UI 不永久堆满来源日志，细节由选中对象展示。

## 5. 清单与交付目录

每批目录：delivery/art/<batch-id>/，含 manifest.json、models/、textures/、sources/、preview/、LICENSES.md、CHANGELOG.md。工作区只交付资产，不直接编辑主工程；Work A 导入 assets/art/ 并维护映射。示意结构不是已创建的文件。

manifest.json 示例（占位资产，不代表已交付）：

```json
{
  "schemaVersion": 1,
  "batchId": "riverbank-placeholder-001",
  "assets": [{
    "id": "plant.placeholder.a", "revision": 1,
    "kind": "model", "uri": "models/plant_placeholder_a.glb",
    "unit": "meter", "forward": "+Z", "up": "+Y",
    "pivot": "ground-center",
    "bounds": {"min": [-0.25, 0, -0.25], "max": [0.25, 0.8, 0.25]},
    "materialMode": "cutout", "alphaCutoff": 0.5,
    "clips": [], "tags": ["placeholder"], "licenseRef": "LICENSES.md"
  }]
}
```

id 稳定且唯一；revision 变更时保留历史；uri 为相对路径，不能指向制作电脑绝对路径或网络。bounds 使用本地坐标米；主工程产生导入摘要 SHA-256。文件名小写 ASCII 加下划线，内容命名不依赖中文路径。许可证记录作者、来源、授权范围、是否 AI 生成及可用凭据；不能使用来源不明素材。

## 6. 初始预算（工程目标，尚未实测）

| 指标 | 手机档 | 桌面档 |
| --- | ---: | ---: |
| 同屏 draw calls | ≤80 | ≤150 |
| 同屏三角形 | ≤80,000 | ≤200,000 |
| 单贴图建议上限 | 1024² | 2048² |
| 初始可玩资源压缩传输 | 目标 ≤10 MB | 同一基础包 |

预算针对全场景，不是每个资产；对象数量由模拟和性能一起决定。重复植被优先实例化，远景使用合并/简化，不删除真实模拟对象来伪造运行结果。手机降低像素比、阴影与粒子，保留规则。预算未经目标手机实测，不承诺帧率。

交付需附顶/侧/背视预览、尺寸、动画清单、材质数量、三角形数与文件体积。缺失资产使用明确占位，不静默改变玩法。尚未验证：GLB 导入表现、透明排序、360°背面、手机显存与正式风格一致性。

## 7. 网格、方向与导出补充（待审核）

建议基础地表格 cellSize=1米，可配置，原点 (originX,originZ)。格(i,j)中心=(originX+(i+0.5)*cellSize,heightAt(x,z),originZ+(j+0.5)*cellSize)，边界归属用floor，不以摄像机角度或像素取整。地形顶点高度与植被占格独立，旧12像素植物格/20像素气味格必须分别适配，不能混用比例。网格精度是工程提案，待主设计批准；不将物种尺寸限制为整格。

未来建筑以稳定实体ID、米制footprint多边形、yaw、占用格集合放置；道路使用世界坐标折线影响通行成本，无须新增另一套坐标。当前不制作建筑或城市素材。

多方向精灵作为可选简化：8方向，角度以+Z为0、向+X为π/2，方向由相机相对实体角决定，所有帧统一底部枢轴、尺寸和占地；高俯仰或近景侧看需要GLB替代，不用一张图假装全部角度。8方向不是首批强制制作量。

现有运行代码支持湿地PNG与程序绘图；GLB、WebP、动画clip和图集读取尚未实现。本规范声明的是v0.5拟支持接口。首批推荐PNG+简单GLB，不用DRACO/KTX2等额外解码依赖。单个普通植株目标≤1000三角形、单GLB≤1MiB、单贴图压缩≤1MiB；地形/大型资产另列预算，不能每个对象都占满场景预算。图集≤2048²且提供1024²手机版。未实测。

交付manifest添加 specVersion、assetRevision、sourceAppVersion、exportSettings；文件修改递增revision、不复用旧摘要；单位/枢轴变化属于破坏性接口变更，先提交 Work A 和主设计确认。导出前应用单位缩放，记录包围盒、材质/贴图数量和各clip持续时间。
