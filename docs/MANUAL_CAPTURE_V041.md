# v0.4.1 人工截图与录屏交付步骤

1. 在这台Mac的Chrome/Edge打开http://127.0.0.1:4176，或手动打开原v0.4.1单HTML；确认版本，完成一次人工操作检查。不要录v0.5原型冒充保底版。
2. 进入实际核心玩法后再开始录屏。Mac按Shift+Command+5，选择录制游戏区域；不要把桌面聊天、账号或其他窗口录入。系统声音能否录到取决于当前录制工具，先短录试听，不承诺该快捷键自动录入游戏声音。
3. 录一段约30～90秒真实操作，开头5秒展示核心玩法，连续操作至少10秒；不要用菜单、概念图或剪辑过场替代。完整体验验收另做，短视频不证明已通关。
4. 交付MP4/MOV，时长>15秒，短边至少540像素；游戏区域占画面主体。不要加游戏外字幕、配音、他平台水印。
5. 用Shift+Command+4人工截取至少3个不同的实际玩法画面，例如播种后的变化、蚂蚁运输、飞鸟携种。横图至少1280×720，保持同一比例，每张≤4MB。若当前可见画面不足尺寸，先调整游戏窗口，不放大低清截图冒充高清。
6. 文件命名v041_gameplay_01.png等；视频v041_gameplay.mov；放入交接目录中的“人工待补素材”或提供实际路径。记录录制日期、设备、浏览器、构建与是否实录声音。
7. 用户进入后台按实际槽位上传，再核对预览与赛事关联。出现拒绝信息保留原提示交回，不擅自改已冻结包。

以上指标来自[TapTap物料要求](https://developer.taptap.cn/docs/store/release/publish/material/)。图标/小封面不是玩法截图，1920×1080宣传图也不能用简单截图替代。本轮未代录、未自动截图、未做自动试玩。
