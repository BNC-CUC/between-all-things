## 6. 渲染和坐标方案（提请审核）

选择 Three.js + WebGL2 的真实三维场景承载 2.5D 纸片表现：地形有高度、实体有世界位置与遮挡，植物可使用薄片或低面数模型。官方 WebGLRenderer 使用 WebGL2，当前不支持 WebGL1，因此低能力设备须显示明确提示，不能默默换成失去坐标一致性的二维版本。[官方说明](https://threejs.org/docs/pages/WebGLRenderer.html)

依赖在实施时锁定具体版本及许可证，运行包自带模块、贴图和音频，不依赖在线 CDN。当前尚未安装或固定 Three.js 版本。H5 使用静态目录；离线首先保证本地服务器启动的完整离线包，浏览器直接双击单 HTML 的兼容性另列交付项，不冒充已完成。生产包不得依赖远程字体或素材 URL。

**世界约定：**右手系，Y 向上，X 向东，Z 向南；1 单位 = 1 米，旋转为弧度，时间秒。地面规则索引为 (x,z)，高度由 terrain.heightAt(x,z) 取得；飞行实体拥有独立 y。旧二维 (x,y) 转为新 (x,z)，比例由迁移适配层统一声明，不能在各素材中各自缩放。地图范围与模拟格长待规则设计给定。

**摄像机：**正常观察用透视投影，建议初始 FOV 35°、地平线上方仰角 25°～75°，水平角不限圈数。俯视建设切到正交顶视并保留焦点和近似可见范围，提供复位按钮。以上角度是首轮起点，不是已验证体验。

**垂直 180°实验：**定义为极角 θ 从 0 到 π，即从正上方经侧面到正下方；不等于仰角 ±180°。正常模式不允许进入地下观察。实验模式使用独立相机姿态计算，处理极点方向连续性；精确顶/底视使用固定稳定基向量，不能假设 OrbitControls 自带完整极点穿越能力。底面观察默认禁用建设，显示“观察模式”。OrbitControls 可作为正常环绕、缩放和平移基础。[官方控制器文档](https://threejs.org/docs/pages/OrbitControls.html)

**拾取：**指针位置减去 canvas 客户区偏移，归一化为 NDC，由当前相机发射射线，与可编辑地形或专用交互碰撞体求交。返回 {position, normal, surfaceId, entityId?} 或 null；点击 UI、无交点、背面或不可编辑区域不能产生世界命令。输入不按屏幕像素直接修改世界坐标。预览与实际提交共用同一个命中和规则校验结果。

**移动与观察：**平移基于摄像机在地面的方向；缩放围绕有效焦点。鼠标左键执行选定工具，右键拖动观察，中键平移，滚轮缩放；触屏单指使用当前工具，双指缩放/平移，专用观察模式单指环绕。手势结束后才提交点击，拖动取消点击；具体手势阈值尚待体验确定。

## 7. 模块与共同事件接口（draft-1）

建议目录：src/sim、src/commands、src/render、src/input、src/audio、src/ui、src/save、assets、vendor。模拟不引用 DOM、Three.js 或音频节点。

- simulation.step(dt) 推进真实规则；首轮建议固定 1/30 秒，渲染插值，后台暂停且不一次追赶无限时间。
- commands.dispatch(command) 校验工具作用范围与资源后提交，返回 accepted/rejected 及原因；具体规则由主设计定义。
- renderer.sync(snapshot) 只读模拟快照，镜头变化不得改变模拟结果。
- eventBus 推送已发生的状态变化；渲染和声音消费事件，不能反向制造资源、出生或完成状态。

共同事件字段：schemaVersion:1、eventId:string、type:string、simTime:number、position:{x,y,z}|null、entityId?:string、actionId?:string、causeEventId?:string、payload:object。eventId 在同一存档会话唯一；actionId 关联玩家命令，causeEventId 关联直接原因，不把所有后续生态变化都归功于玩家。位置统一世界单位。重放/读档默认不重播历史声音。

命令至少含 commandId、type、worldPosition、参数、issuedAtTick；结果含 commandId、accepted、reasonCode、产生的 eventIds。工具名称与参数白名单在正式规则接入时冻结。ART_SPEC 与 AUDIO_SPEC 共用以上事件，不自行发明另一套坐标。
