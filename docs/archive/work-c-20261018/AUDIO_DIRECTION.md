# v0.5 声音方向与主工程交接需求

2026-10-18 · Work C · 设计稿1。正式 AUDIO_SPEC.md 尚未收到；下面是内容与行为提案，不是已实现接口。

## 声音想让玩家感到什么

像在湿地里照看一小块会自行生活的地方：可以长时间停留，也可以专注一次播种。声音首先帮助辨认“我刚做了什么”和“那件事后来怎样了”，其余生命保留空间和安静。生态繁盛不等于音量增加、音符增加或每只动物都发声。

音乐采用温暖、稀疏的环境配乐：柔软气息、低密度拨弦、木质触感和少量透明泛音。暂用 D、E、G、A、B 的共用音高集合，允许无音高的水土声；具体调域待主工程规范与音色试听确定。无歌词、无持续鼓点、无强烈胜利号角，不模仿某个具体游戏或在世作曲家的辨识风格。

长时间观察靠留白维持舒适：环境持续，音乐短暂出现后退出。所有角色处于同一个音乐空间，切换只改变近处声音的关注点，不重启一首歌。

## 层次与空间

| 层 | 内容 | 密度和相对关系 | 变化依据 |
| --- | --- | --- | --- |
| 环境底层 | 浅水、柔风、雨叶；可选远虫 | 常态最多2层；天气交接时暂允许3层。最安静，不能覆盖交互 | 位置、天气；用4—8秒平滑变化，避免每帧追随数值抖动 |
| 音乐 | 一个轻薄和声床，可选一条稀疏短句 | 常态最多1条音乐轨；曲段交接最多2条且等能量过渡。短句与和声床错开，不额外常驻 | 与按键无关；世界稳定变化可影响出现概率，有上限 |
| 近处生活 | 少量翼动、植物舒展、远鸟回应 | 群体合并为少数位置；一群蚂蚁不产生几十组脚步 | 当前观察范围内的真实活动；看不见且很远的活动默认不发点状声 |
| 玩家行动 | 闪光、播种、拾取、搬回、施肥、落种 | 清楚、短、柔；同材质少量变体，少混响 | 接受的真实动作，不按每次输入重播 |
| 后续结果 | 被关注种子的萌发、同伴真实回应、生态目标达成 | 比环境清楚，但不比操作声猛烈；单次出现后留空 | 真实结果、因果标识、曾关注的对象；不对所有自然生长报喜 |
| 界面 | 切换视角、进入回望 | 很短且可省略；回望变安静，不变成新的演出 | 用户切换成功；快速切换只保留最后一次 |

音乐编排提案：90秒和声片段两种，播放一段后留20—40秒仅环境的空间；可选8—14秒短句，在这些空隙中偶尔出现，同一短句至少间隔90秒。初期宁可只用和声床，不让音乐承担生态报警。不得把循环片段中的鸟叫、滴答或旋律重音做成固定计时器。

点状音效优先交付单声道干声，由主工程按位置处理；环境与配乐为立体声。声像不硬贴左右，不把界面音假装放在世界坐标中。回望时不监听全图的每个对象，只保留柔和环境、音乐和少量玩家关注对象的结果提示。

## 事件需求与防重复规则

下表是推荐初值，收到 AUDIO_SPEC.md 后对齐。冷却在声音侧限制声音，不限制游戏行为；被丢弃的低优先级事件不排队补播。即使静音，玩家也应能通过画面知道结果。

| 游戏事实 | 所需声音与资产ID | 建议触发与上限 | 不应表达的含义 |
| --- | --- | --- | --- |
| 玩家闪光 | FX01；有实际邻居回应时FX02 | 主声随有效动作；同一次传播最多1个回应声，回应间隔至少3秒 | 每一个传播节点都需要报数 |
| 播种实际增加植株 | FX03 | 一次播种图案1声，至少0.5秒间隔 | 在已占据位置播种也已成功 |
| 种子真正萌发 | FX04 | 玩家追踪种子每个对象1次；周边自然萌发4秒内合并为1声 | 着地就等于萌发 |
| 成熟与结实 | FX05用于可辨认的结实；成熟暂不单独制音 | 当前观察区域至少8秒间隔；远处静音；同一植株短时不重复报喜 | 每细胞每次更新都应响，或结实全部由玩家促成 |
| 食物、种子、养分被玩家拾取 | FX06、07、08 | 携带状态从空到有时1声，至少0.2秒去重；NPC拾取默认静音 | 仅仅靠近资源就已拿到 |
| 食物回巢 | FX09 | 玩家每次真实卸下1声；NPC返巢合并且至少6秒间隔 | 高频NPC送达比玩家更重要 |
| 养分进入土壤 | FX10 | 玩家真实送达1声；同岸NPC补给至少6秒间隔 | 这只是又播了一次种 |
| 携带物移动途中 | 默认静音 | 不为每步、每帧或每格位移制音 | 移动必须持续播放循环搬运声 |
| 留下气味 | FX11 | 接受的动作最多每0.8秒1声；长按不额外补声 | 已有同伴采用这条路 |
| 玩家鸟鸣 / 同伴回应 | FX12 / FX13 | 主鸣至少2秒间隔；同一呼叫最多1个真实回应，回应至少4秒间隔 | 听见就等于转向成功、落种成功 |
| 释放种子 | FX14 | 每颗实际释放1声 | 已经落地或萌发 |
| 种子接触岸地 / 深水 | FX15 / FX16 | 玩家追踪对象各1次；普通NPC着地默认静音；与萌发严格分开 | 落水只是另一种成功 |
| 干旱、养分不足、种子失败 | 默认无新资产 | 视觉说明优先；未来若确需声音，仅玩家关注对象状态改变时一次，不循环警报 | 需要立刻抢救的倒计时失败 |
| 鸟群飞过 | FX17（P1） | 距离近时一次群体翼动，至少12秒间隔；不按每只鸟扇翅触发 | 离屏动物数量越多世界越响 |
| 蚂蚁活动、自然凋落与腐败 | 默认静音 | 可由环境材质暗示；不制作逐只脚步或逐株死亡提示 | 正常循环是失败或异常 |
| 视角切换 / 回望 | UI01 | 至少0.6秒间隔，合并快速切换；回望优先渐弱局部事件 | 切换角色值得播放一段奖励琶音 |
| 世界目标实际达成 | END01 | 每个世界首次达成一次，完成后继续观察不反复响 | 生态从此不会变化或恶化 |

## 防止听觉轰炸的总预算

1. 短音效同时最多4个逻辑声音，其中NPC/环境事件最多2个；一个音效的所有声部和尾音合计为一个逻辑声音，其持续时间计入预算。主工程还需控制实际声源数。
2. 非玩家事件全局最多每2秒启动1声，并满足上表更长的局部冷却；优先合并同岸、同类事件。按距离筛选后才占预算。
3. 玩家接受动作的短反馈优先，建议至少120毫秒去重；满额时替换最弱的NPC事件，不叠加新一层。重要结果若同刻出现，保留一个结果提示，其余记入画面，不延迟排成提示队列。
4. 同一因果链必须区分阶段：落种、着地、萌发各有状态；禁止一次萌发同时播放“播种+落地+成功”。每个事件有唯一标识；没有去重信息时宁可减少声音。
5. 重复反馈做2—4个同响度变体，避免连续相同；变体不意味着增加播放次数。任何随机音高、速度变化以不破坏音色为前提，先试听后决定幅度。
6. 主要动作出现时，环境与音乐可以轻退约2—3dB，0.2秒退、1—1.5秒恢复；频繁动作期间保持较低状态，避免抽吸。具体数值以实际混音为准。
7. 暂停与离开页面渐弱；恢复不追补事件。新旧声音系统如并行存在，主工程必须确认哪些旧事件关闭，防止同一动作双重播放。
8. 不靠“把所有素材都压到很响”来确保可听；先减少同时发声，再调平衡。高频鸟鸣、细碎点击、长混响尤其要克制。

## 制作与导出提案（未冻结）

- 母版暂拟 WAV / PCM / 48kHz / 24bit。点状音效单声道，环境、音乐立体声。运行时编码、比特率、兼容回退与是否内嵌，必须等 AUDIO_SPEC.md。
- 短音效保留必要尾音，按听感匹配同组变体，不逐条拉到相同峰值。母版留至少约3dB真峰值余量作为初始目标，最终混音峰值仍需主工程整体验证。
- 音乐暂拟 -24 LUFS-I、环境暂拟 -28 LUFS-I 作为制作参考，不作为已经测量的结果或系统音量值；极短音效不用单一综合响度数值判优劣。清单实际测值在导出后填写。
- 环境循环母版计划60秒，音乐90秒；循环起止、尾音、是否需要交叉淡化、编码后接缝均要单独登记。提供完整立体声文件，不预设主工程支持分轨同步。
- 第一批只做最小必要声音；P1为可选，不为“事件都有声音”扩大数量。首批运行时包体目标暂拟≤8MiB，最终以主工程预算为准；母版不计运行时包体，也不把体积估算写成实测。
- 暂拟原创合成与自制材质，不在本阶段引入来源不明的外部音乐。后续任何录音、素材包或生成工具均记录作者、来源、许可或使用条件、AI参与方式；现在不承诺尚未制作素材的权利状态。
