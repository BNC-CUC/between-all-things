## 规格约定

- 拟定母版：WAV / PCM / 48kHz / 24bit；表中逐项标明声道、目标时长与循环用途。规格为提案，等待 AUDIO_SPEC.md。
- `{01..NN}`表示同用途的独立变体；单变体文件不加范围后缀。所有变体应匹配听感，不连续重复同一变体。
- 运行时格式、编码参数、实际包体：待规范；循环点、实际时长、峰值、响度、SHA-256：未生成，不填虚构测值。
- 各项的触发对象、冷却、聚合与语义限制以 AUDIO_DIRECTION.md 的事件表为准，资产本身不能保证限频。

## 明确不逐事件制音的项目

蚂蚁每步、植物每次细胞更新、携带途中每次位移、每株死亡、每次气味扩散、每只鸟扇翅、全世界每次自然萌发均不单独制音。成熟、缺水、低养分、种子等待失败暂以视觉和环境层表达，不加入循环警报。
