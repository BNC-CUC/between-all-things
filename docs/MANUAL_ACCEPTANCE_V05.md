入口：http://127.0.0.1:5050（仅本机）。刷新载入新构建；刷新会重置世界，暂未实现存档。此为首条创造循环原型，不是正式参赛包；数值和占位外观待审。

## 空间操作

- 自由观察：左键拖动环绕，右键/中键拖动平移，滚轮缩放；水平可连续转圈。
- 俯视建设：切换正交顶视；拖动平移，点击使用当前工具。
- 触屏：单指轻点工具、拖动观察；双指缩放和平移。真机手势尚未验收。
- 恢复视角：恢复镜头，不清空世界。
- 实验俯仰：可接近上下极点，顶视/底视按钮提供端点；地下只观察，不能使用工具。连续穿越极点尚未实现。
- 暂停世界：暂停模拟但仍可观察/编辑；再次点击继续。后台页面暂停模拟，不追赶离开期间时间。

## 亲自走一次创造循环

1. 选择“播种”，在左侧岸地、棕色巢附近的多个空格轻点。小芽表示种子已进入世界，不是预设成熟动画。
2. 指向土地查看水分与肥力；选“浇水”/“补充肥力”点击附近，工具作用于半径2米的局部土地。湿度或肥力不足时植物停长并偏褐色，不循环报警。
3. 暂定理想环境成熟约24秒，再约12秒首次产果；环境较差会更久，不能把此时间当作正式承诺。充分浇水/补肥后更容易观察完整链条。
4. 金色果实是真实资源对象。六个占位搬运者会选择可达果实，沿地面格寻路，拾取并带回棕色巢。观察“地面果实/已运回”变化。
5. 选择“搬放果实”，先点地面金色果实附近，再点另一处岸地。被选果实变大；已被搬运者拿走的果实不能再搬放。尝试移远，观察下一次寻路改变。此工具是沙盒直接布局，不是瞬移动物。
6. 在不同水肥土地播种，对比生长；水面不允许播种，也不能由地面搬运者跨越。隔岸资源可能不可达，属于当前地形规则，不会播放假运输动画。
