# 河湾之初｜第一阶段实施计划
2026-10-18。状态：技术计划已完成，架构已批准，H空间灰盒已编码/构建，人工体验待验收；I生态玩法尚未开始。

已确定循环：玩家改变土地 → 植物生长 → 资源出现 → 自主生命改变活动 → 新的创造可能出现。工具为播种、湿度/肥力干预、可搬运资源布置；共同修改同一World，不播放三段预制演出。

持续结果A：局部水肥及播种建立有自我更新的植物群落；结果B：植物产出和资源位置改变自主运输网络。具体生长阈值、资源种类/数量、动物清单、工具成本/范围、是否及如何产生新创造机会需主设计细则；不自行加建筑解锁或胜利任务。

先行实现限定在架构批准后：占位地形、自由镜头、准确拾取、工具预览、纯数据命令边界。随后最小闭环优先于高级水面/全套音效；不为正式素材等待停止占位实现。不安排城市、居民、文明或实验室实现。

风险：两套旧网格比例不一致、旧角色/目标耦合、种子和资源重复生成、音效误归因、透明遮挡、离线模块路径。处理：统一映射、提取纯函数、原子资源转移、因果ID、真实深度、本地资源索引。所有发布到公开站点/投稿须另行授权。

赛事优先：现在核实后台审核；保留v0.4.1发行候选。距离截止短，不承诺v0.5全量赶上；仅把经过主设计验收及人工试玩的功能放入新参赛包。未通过时保持已确认可用的保底版本，不能用源码检查替代可玩性验收。
