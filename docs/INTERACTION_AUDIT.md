# v0.5-loop.2 当前交互问题清单
2026-10-18｜基于index.html、src/main.mjs及模拟/命令代码的静态审计。用户已人工试玩并否决当前体验；以下具体原因是代码分析，不冒充新的观察测试。只提交问题，不实施新玩法。

| 环节 | 当前实现 | 问题与影响 | 优先级 |
| --- | --- | --- | --- |
| 初次进入 | 浅色地形、几何体蚂蚁/巢、左上工具与数值面板；有存档会恢复此前世界 | 缺少可识别生命和具体创造对象；空地与操作表无法建立第一愿望；恢复状态也会改变第一印象 | P0 |
| 识别对象 | 地表悬浮圈；可编辑性主要按地面判断；植物/资源/巢为基础几何体 | 看不出蚂蚁、巢、可搬食物的身份；没有统一可交互对象提示，水域等拒绝常发生在点击后 | P0 |
| 播种 | 选播种后点地表；左键拖动环绕，超过位移阈值区分点击 | 同键移动镜头/创造，意图容易冲突；放置成功不等于看懂植物后续需求 | P0 |
| 水肥 | 选择工具后点地；局部半径作用统一状态 | 作用范围缺少明确预览；效果主要在数字或观察层，玩家难读出边界、持续性和为何有效 | P0 |
| 资源移动 | 第一次点附近地面果实选中并放大；第二次点落点；文字状态说明 | 点选依赖距离阈值；候选、选中、取消、合法目的地与搬运中资源限制缺乏完整视觉语言 | P0 |
| 生长 | 大小/色彩随状态变化；水肥层和地表指标可查看 | 慢变化缺少局部解释，干旱/停长/衰退难区分，玩家难归因于自己 | P0 |
| 植物→果实→蚁巢 | 果实球出现，蚂蚁运输，巢储备计数变化 | 因果链实际存在但身份、发现、领取、携带、卸载阶段不够可见；统计增长不等于完成反馈 | P0 |
| 饥饿与腐败 | 储备影响速度，果实变暗后消失并回肥 | 看起来可能是速度故障或资源消失；为何变化及对下一轮生长的作用主要藏在数据 | P1 |
| 路径形成 | activity累积和衰减影响导航成本，方格层可观察 | 方格热度不能自然读成持续运输路径；不易理解系统接管了重复劳动 | P1 |
| 目标和结果 | 操作提示、统计、多个观察/存档控制；无已验收体验结构 | 玩家知道能点按钮，却不清楚值得关心什么、探索什么、何时创造有效；恢复视觉本身不能修复此问题 | P0 |
| 声音与反馈 | v0.5尚无正式音效及集中播放器接入 | 主动动作与自然响应缺少声音区分；不能靠补环境音乐代替因果反馈 | P1 |
| 信息层级 | 左上可滚动面板集中工具、模式、存档和数字 | 建设、观察、调试信息争夺注意力；资源账本、肥力、有机物、巢储备等过度依赖面板 | P1 |

人工操作参考仍见MANUAL_ACCEPTANCE_V05.md：左键点工具作用于地表/拖动环绕，右键或中键平移，滚轮缩放；俯视切换、默认视角、资源两次点击。该指南只是操作说明，不证明体验合格。

交互整改需设计区先明确：首个可理解对象、玩家行动的动机、每步局部反馈、传播过程、结果归属与持续状态的表达。本轮不自行增加任务链、计分、章节或解锁来掩盖问题。
