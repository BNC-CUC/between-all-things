# 协作与版本同步流程
2026-10-18。

1. 主设计发布带版本、日期、确认状态的正式原文；Work A原样归档并更新DESIGN_MASTER/DECISIONS，提案与批准区分。
2. Work A提交接口草案；主设计确认后标明approved版本；Work B/C依批准版制作，维护各自清单内容，提供批次、摘要和许可。
