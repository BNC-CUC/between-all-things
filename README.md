# 万物之间 · 生命涌现实验 v0.3

从一粒微光，进入一个彼此相连的生命世界。这是对《第七只》v0.2 的独立创作实验，旧版没有被覆盖。

## 直接打开

打开 `release/万物之间-生命涌现-v0.3.html`。画面、音乐、脚本和湿地原画均内嵌，离线可用，无需安装游戏引擎或下载依赖。

其他交付：`release/BetweenAllThings-H5-v0.3.0.zip` 是包含单一英文外层目录的 H5 包；`release/BetweenAllThings-source-v0.3.0.zip` 是该实验的源码包。发行文件是直接打包的实验产物，尚未进行运行验证，也尚未提交比赛。

## 从哪里开始

点击「成为第一粒光」。按住画面或使用 WASD / 方向键移动，空格执行当前生命的主要行动。金色描边的个体是玩家。

1. 微光：游近邻居闪烁。局部回应会沿邻居传播；让至少 48 个生命接到回应，合拍程度达到 68%，并亲自发出至少两次闪光。
2. 生长：视角交给一枚孢子。在两处湿润地面按空格播种，E 切换三种初始图案。生命采用邻近格子的出生与存活规则，产生至少 28 次新生和三份岸边食物。
3. 道路：成为一只探索的蚂蚁。靠近食物自动拾取，回巢自动放下。携食行走持续留痕，空格加深气味。自己带回一份食物，并让三次同伴的搬运使用过你留下的路径。
4. 飞行：成为一只持续向前飞的鸟。飞近岸边草丛携带草籽，空格鸣叫，转向经身边同伴传递。至少八只鸟接过影响；自己在最初微光上方的绿色区域按 E 落种，等待新斑块开始生长。
5. 回望：镜头逐渐拉远，展示所有仍在运行的生命联系。可以选择下方的生命印记重返已经历的视角。

完成每种联系后，右侧出现切换视角的按钮，也可以按 Enter 继续。切换前后世界不重置。V 拉远或回到当前个体；Esc 暂停。触屏使用屏幕按钮。

## 这次改变了什么

- 开始于可看清形态和回应的微观生命，不再默认全程控制鸟。
- 原来的五条创意通过同一个世界中的状态联系串起来：局部同步 → 生长条件 → 有机质与食物 → 气味路径与资源积累 → 鸟群与种子归来 → 新生。
- 干预作用于邻近个体，传播形态、细胞图案和道路由规则生成；旅程的顺序和完成条件由设计编排。
- 镜头从微观、植物近景、蚁群地面过渡至天空和全景。已发生的变化在其他尺度继续存在。
- 强化首个回应、传播线、携带状态、搬运、落种、资源转移和完成后的持久变化。
- 提供每种身份的即时目标、身体标记、当前动作、传播关系提示、进度和可返回的生命记忆。
- 鸟维持前进、有限转弯速度、倾斜、振翅和高度变化；微生物受漂流影响；蚂蚁可以停步。

## 创作边界

这是一个写意的虚构生态。发光生命、生长斑块、蚁群、岸边草丛与候鸟之间的资源关系是游戏设计，不把它描述成现实中已证实的食物链或生物演化史。不同身体是视角接力，并非同一个动物瞬间变形。

这里没有网络服务、账户、上传、遥测、第三方运行依赖或外部音频。音景由浏览器在玩家主动开始后合成。旧湿地原画被作为连续地景复用，新增细胞、植物、蚂蚁、种子和鸟群绘制在其上。

## 本地开发

在当前目录运行 `npm start`，本地端口为 4174。`npm run package` 仅生成发行包，不执行测试。项目是构建步骤很少的 HTML / CSS / JavaScript，不需要安装依赖。

本轮遵照用户要求，没有执行单元测试、语法检查、浏览器验证、截图检查或自动通关。打包成功不代表运行质量、可玩性或设备兼容性已被确认。
